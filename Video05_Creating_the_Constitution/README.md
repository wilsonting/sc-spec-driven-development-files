# AgentClinic

## Input from stakeholders

- Mary in engineering wants a reliable site with a popular stack based on TypeScript, giving agents and staff a dashboard for easy access.
- Susan in product has a set of features about agents and their ailments, therapies, and booking appointments.
- Steve in marketing wants an attractive site that works well with a modern browser.

## Getting started

Prerequisites: [Node.js](https://nodejs.org) 24 or newer (`nvm use` picks it up from `.nvmrc`).

```sh
npm install
npm run dev    # http://localhost:3000 (set PORT to change it)
npm test
```

Other scripts: `npm run build`, `npm start`, `npm run lint`, `npm run format`, `npm run typecheck`.
